Estou em constante evolução na área de cloud computing, buscando aprofundar meus conhecimentos em infraestrutura, observabilidade e boas práticas de confiabilidade e eficiência em ambientes cloud, com o objetivo de evoluir para uma atuação como SRE/DevOps.
